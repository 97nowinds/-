# 实验室迁移与基础标定向导方案

状态：设计方案；尚未实现安装向导、自动交接建模或自动验收。本次不修改运行中的跟踪服务。

## 目标

非技术操作人员不改代码、不编辑 JSON、不调 ReID 阈值、不手画摄像头交接门区。提供一个入口完成连接摄像头、建立地图、地面点选标定、走动验收及配置备份。

## 当前代码事实

- `app.py` 已支持 `LAB_FLOOR_MAP_PATH` 与图像/地图四点标注保存，当前激活检查仅确认每路有四组点；四点存在不能证明精度达标。
- `config/floor_map.json` 包含本实验室地图、摄像头标定、交接拓扑、门区、重叠许可及路线参数；整份复制到另一实验室会带入错误几何和路径。
- `config/cameras.json` 存在按当前相机设置的检测尺寸、抽帧和阈值；启动脚本含本实验室 IP 默认值。
- 副通道修复已说明跨摄关联不能仅靠地图四点标定：还需要实际可见路径、重叠/盲区及外观连续证据。

## 操作人员流程

1. **连接摄像头**：选择发现的摄像头或填写地址和账号，测试画面。系统检查分辨率、流是否重复、画面持续更新与延迟；指定入口摄像头为一个普通选项。硬件、网络及计算服务首次准备属于部署前置条件。
2. **准备平面图**：上传平面图或创建简单布局，填写一条实际长度建立米制比例。选择现场能明确找到的地面位置作为控制点；地图本身不准确时不能宣称有准确米制位置。
3. **点选地面标定**：每路摄像头至少四个不共线、覆盖活动区域的地面点，按编号在视频和地图中各点一次。可放置编号地贴帮助配对。界面提示点错、共线、覆盖不足；不使用桌面角点代替地面点。
4. **引导走一圈**：界面逐条提示“从摄像头 A 区域走到 B 区域并返回”。记录真实图像、局部轨迹、身份、时间和地图位置。系统提出交接路径、门区、重叠与盲区候选，不让用户编辑关联参数。
5. **查看验收**：用未参与拟合的地面检查点核验位置，核验正反向交接、身份断开/恢复、重复点和时延。显示通过、需重新点选、视野有盲区或关联待确认；不因为配置保存成功就显示通过。
6. **保存实验室配置包**：保存地图、标定、相机逻辑编号、交接证据、模型版本、验收报告。凭据独立保存，不进配置包；搬动摄像头后提示重新验证。

第一次安装或摄像头调整时走动验证不可省略。以后启动复用通过验收的配置，不需每次标定。需要多人使用时，还必须增加两人交叉/同行验证；单人走动通过不能保证多人不串 ID。

## 系统实现范围

- 将算法/模型版本与实验室配置分离，保留当前现场配置独立存档。
- 提供新实验室模板，清空旧地图、区域、标定和已验证重叠信息；保留通用模型与安全默认值。
- 将启动脚本、模型校验、连接诊断封装到向导；不复制本实验室 IP 或 SSH/RTSP 密码。
- 标定采用拟合点与独立检查点，显示实际误差；保留不可信/缺位置状态。
- 从带标注的走动验证提出交接配置；证据不足的路径不启用，显示需要补走的路线。不能仅按单人演示自动降低全局 ReID 阈值。
- 自动生成门区与匹配候选仍需验证。盲区不能通过预测位置伪装成连续观测；相机视野不足时给出具体安装调整提示。
- 版本化配置、地图版本一致性、校验、备份与一键恢复。保留已有 Token、身份与隐私边界。

## 实施顺序

1. 保留现有现场版本，先继续解决单人跨摄断连并明确不可见状态；避免把未解决问题作为模板复制。
2. 实现实验室配置隔离与安装包/连接向导。
3. 实现地图与标定向导、独立误差检查。
4. 实现走动引导、交接候选生成、自动验收与备份。
5. 在一间未参与开发的新实验室由非技术人员独立完成流程，记录是否需要编辑配置/终端命令；若需要，则不能算达到低工作量目标。

## 验收标准

普通操作人员完成迁移不编辑代码/JSON、不执行终端命令、不调模型阈值、不手画交接门区。系统显示实际定位误差和交接断连，不承诺所有房间都能只靠四点实现无盲区连续跟踪。现场输入限于摄像头连接信息、平面图与尺度、地面点选、引导走动；额外工作必须由具体失败证据触发。
