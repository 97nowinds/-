## 当前硬件接入方案

环境监测采用 STM32F103C8T6 最小系统板，直接通过 USB 串口连接运行 Flask 预警平台的电脑。电脑 USB 同时提供低压电源和数据链路，不使用 W5500、MQTT、网线或网络 Broker。

`传感器 -> 隔离/调理 -> STM32 -> CP2102/CH340 -> 电脑 COM 口 -> Flask 环境接口 -> 页面/飞书`

## 固定接线

| 用途 | 接线 |
| --- | --- |
| 供电 | USB 转串口模块 5V -> STM32 5V，GND -> GND |
| 串口 | 转串口模块 TX -> PA10，PA9 -> 转串口模块 RX |
| I2C 温湿度 | PB6/PB7 |
| RS485 设备 | PA2/PA3/PB12，经隔离 RS485 模块 |
| 烟雾/火焰触点 | PB10/PB11，经光耦隔离或 3.3V 调理 |
| 模拟量 | PA0/PA1，经 0-3.0V 调理 |
| 调试 | PA13/PA14（SWD） |

串口模块使用 CP2102 或 CH340，必须为 3.3V 串口逻辑。只允许一个 5V 电源输入。24V、4-20mA 和长线传感器需要独立供电和隔离/调理，不能直连最小系统板。

## 软件接口

- 串口参数：115200，8N1，UTF-8 JSON Lines。
- 每 2-5 秒上报遥测；状态变化立即上报告警。
- 电脑侧 `serial_worker` 读取 COM 口，并调用 `POST /api/environment/ingest`。
- 30 秒未收到有效数据则判定硬件设备离线。
- 飞书 Webhook 仅在电脑可访问互联网时发送；本地网页预警不依赖联网。

## 安全边界

烟雾、火焰和气体认证报警器应保留独立现场报警回路。STM32 与电脑只做辅助监测和预警，不控制急停、安全继电器或危险负载。
