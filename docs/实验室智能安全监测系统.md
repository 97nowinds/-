# 实验室智能安全监测系统

更新日期：2026 年 11 月 14 日
适用对象：实验室使用人员、部署维护人员及项目交接人员
版本基线：Gitea 标签 `2026-11-11`（`e31e978c`），大屏空帧修复见 `aa9d0902`。本说明也记录此后在线下开展的模型评估。

## 项目用途

系统在实验室摄像头画面中跟踪人员，将位置投影到平面地图，识别人员与仪器的交互，并展示防护穿戴、环境告警和历史事件。仪器资料库和配置向导用于维护参考照片、生成待复核的仪器识别结果及配置位置。

## 系统组成

| 模块 | 实现与数据流 |
| --- | --- |
| 视频与人员 | 实验室主机通过 FFmpeg 推送 `cam_1`、`cam_2` 和 `cam_entrance`。集群用 MediaMTX 接收，经 YOLOv8n 检测、ByteTrack 跟踪、ArcFace 和跨镜关联，输出人员框、身份及地图位置。 |
| 仪器交互 | 交接服务接收同帧图像、人员框、已有身份和地图坐标。按人员平面位置选择附近仪器，再用 MiniCPM 联合判断。确认后的事件记录开始、结束和持续时长；丢人或断流时保留中断或结束未确认状态。 |
| 防护穿戴 | 当前口罩由 AIZOO 判断。当前实验服由 MiniCPM‑V 4.6 对人员裁图做图文推理，输出已穿、未穿或未知。模型输出进入事件确认规则；最终记录可绑定已确认的人员身份。 |
| 展示端 | Python 前端服务与 JavaScript 页面提供实时地图、三路摄像头和通知。Three.js 绘制 3D 场景。集群空帧会被拒绝，大屏会切换到本机 3D，浏览器无法绘制时显示地图。 |
| 仪器配置向导 | 本机冻结待识别图像和当前资料库状态，将任务送往集群，返回候选、遮罩和复核数据。确认生成结果属于向导配置流程。 |
| 事件与通知 | 管理端保存事件和投递状态，并按已配置的路由发送飞书通知。核对具体事件时应同时查看事件记录和投递状态。 |

| --- | --- |
| 展示大屏 | http://127.0.0.1:5173/display |
| 实时监控与地图 | http://127.0.0.1:5173/monitor |
| 仪器交接与时间记录 | http://127.0.0.1:8765/demo-control |
| 仪器资料库 | http://127.0.0.1:8879/ |
| 仪器配置向导 | http://127.0.0.1:8888/ |

独立展示电脑访问实验室主机的实际局域网地址和 `5173` 端口。主机地址变化时更新展示电脑书签。上述四项服务入口在撰写时已从实验室主机核对 HTTP 响应。

## 部署与排查

1. 摄像头、实时数据、前端和通知服务的启动与配置以 [摄像头部署说明](../camera/README.md) 为准。Windows 常驻任务会管理 SSH 隧道和相关子进程。只重启故障环节，避免中断其他记录。
2. 向导的集群执行脚本和仪器位置快照见 [11 月 11 日部署说明](../deployments/2026-11-11/README.md)。推理权重、录像、原始参考照片、运行数据库和凭据按现场环境保存。迁移时应一并确认这些依赖的位置及访问权限。
3. 展示大屏异常时，先区分页面连不上、摄像头无画面、地图不更新和中央 3D 空帧。摄像头能看而中央只剩标签，优先检查集群帧与本机回退。更新页面后可在展示电脑按 **Ctrl+F5**。
4. 仪器有开始无结束时，按同一人员和仪器对照时间记录、交接帧与模型结果。区分画面里观察到明确的停止，与丢人、断流或证据不足。核对通知时以对应事件的投递状态为准。

## 已验证结果与待验事项

- **仪器配置向导**：集群 RTX 4090 已用预置监控图完成一次新推理，32 份参考图返回 6 项待确认候选，复核接口和图片可读取。即时抓拍仍需完整验收。
- **仪器事件**：开始、结束和时长应使用现场连续操作验证，并逐条对照交接输入、记录页和通知投递。现有记录不足以确认所有仪器及所有断流场景均通过验收。
- **大屏**：局域网已验证实时接口、视频和空帧回退。集群 3D 模型画面的恢复仍待确认，目前可由本机 3D 回退显示。
- **实验服**：同一批 20 张已穿与 20 张未穿的开发样本中，YOLOv8n 分类器判对 27/40，MiniCPM 视觉编码器加分类头判对 28/40。后者把 8/20 张未穿判成已穿，主要集中在同一批 `cam_2` 补充样本。外部 YOLOv5 是白大褂检出器，真穿检出 11/20、未穿误检 4/20。三者均为离线候选。
- **口罩**：公开集子集的 83 个人脸上，AIZOO 判对 55 个，MobileNetV2 判对 70 个。现场单独复核的 7 张允许输出未戴或未知，AIZOO 和 McKlay 都返回未知，MobileNetV2 都判为已戴。公开裁图结果与现场可见性复核采用不同的计分口径。
- **后续 PPE 验收**：同场景补拍白大褂、浅色便服和深色外套，分别标注实际穿戴和画面可见性。按录制批次留出整段盲测，分别统计误报、漏报与未知，避免同一视频的相邻帧同时进入训练和测试。
