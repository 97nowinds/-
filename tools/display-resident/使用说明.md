# Windows 展示电脑常驻

此包只安装在另一台展示电脑。无需复制项目、模型或安装 Python。
要求 Microsoft Edge、Tailscale 已安装，两台电脑处于同一个 Tailscale 网络，网络权限允许连接。

1. 将本目录解压到任意目录，打开该目录的 PowerShell。
2. 运行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\install-display.ps1`。
3. 任务会立即运行，并在当前用户每次登录后自动运行。它等待网页可达后打开专用 Edge 全屏窗口；关闭展示窗口后会再次打开。
4. 在 Windows 设置 → 系统 → 电源中，设置接通电源时不自动睡眠。显示器关闭和电脑睡眠是不同设置。

需要退出常驻时运行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\uninstall-display.ps1`，然后关闭展示窗口。
若任务注册提示权限不足，以管理员身份打开 PowerShell，使用同一个 Windows 用户执行。

脚本每 15 秒检查网页入口。网页中断时保留窗口；网页恢复后重开专用展示窗口。后端数据中断由页面自动重试，不因此反复关闭浏览器。
专用浏览器配置和日志在 `%LOCALAPPDATA%\LabSafetyDisplay`，不修改日常浏览器配置。
本方案是登录后自动展示，注销用户后不能显示桌面；重启后需登录。不设置 Windows 自动登录。

访问地址：
http://100.106.153.101:18080/display?api=http://100.106.153.101:18081
如服务器地址变更，修改 watch-display.ps1 的 Url 默认值并重新安装。

## 服务端依赖

这套脚本不会恢复远端服务。当前电脑仍需保持开机、Tailscale 在线，以及 5173 网页服务和 15001 SSH 后端转发运行。
集群推理服务及摄像头推流也必须在线。Slurm 任务到期停止后，需要按集群规则重新提交。
网页显示“数据连接中断”时，先检查 http://100.106.153.101:18081/api/dashboard 是否可访问。
仅浏览器常驻无法解决集群任务停止、SSH 隧道退出或摄像头断流。
