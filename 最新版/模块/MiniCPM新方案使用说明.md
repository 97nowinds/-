# MiniCPM-V 4.6 人员—仪器交互方案

> 如果需要接近实时速度，请使用 `运行MiniCPM实时优化版.bat`，并查看 `MiniCPM实时优化版说明.md`。本文件描述的是每秒都调用MiniCPM的准确率基准版。

## 当前功能

当前版本只判断一个问题：监控画面中的目标人员是否实际接触或操纵高速离心机。

- `true`：连续画面存在直接可见的接触或操纵证据，例如触碰机身、面板、盖子、门、把手或内部舱体。
- `false`：只是路过、站立、观察、玩手机、拿取旁边物品，或因为遮挡而不能确认真实接触。

它不判断具体在执行哪一种实验操作。

## 最简单的运行方法

1. 找到 `运行MiniCPM新方案.bat`。
2. 把待分析的 MP4 视频拖到这个 BAT 文件上。
3. 保持命令窗口开启，等待“分析完成”。
4. 程序会打开 `outputs\minicpm_v46_interaction`，每次运行会生成一个带视频名和时间的独立目录。

结果目录内：

- `annotated.mp4`：只显示最终“正在交互/未交互”状态的视频，不显示仪器轮廓和手腕点。
- `result.json`：每个两秒窗口的 MiniCPM 原始结论、平滑后的交互时间段及总结果。
- `review_inputs`：实际提交给 MiniCPM 审核的画面拼图，便于排查误判。

## 判定链路

1. 使用固定多边形指定高速离心机，不重新识别仪器类别。
2. YOLO Pose 只提供人员框，用于告诉 MiniCPM 应关注哪一个人以及裁剪有效画面；姿态关键点和手腕距离不参与最终判定。
3. 每两秒抽取 8 帧。第一帧用绿色轮廓标出目标仪器、蓝色框标出目标人员；后续帧不画标记，避免遮住动作细节。
4. MiniCPM-V 4.6 根据连续画面给出二分类 JSON。
5. 最近三个窗口至少两个为真时进入“正在交互”，连续两个窗口为假时退出，以减少单个窗口抖动。

最终是否交互由 MiniCPM 给出，不调用旧版手腕—仪器距离规则。

## 修改前置提示词

提示词是普通文本文件，可直接编辑：

`prompts\minicpm_v46_interaction_system_prompt.txt`

保存后，下次分析会自动读取新内容，不需要修改 Python 程序。调整提示词后应重新测试三个基准视频，避免解决一个误判的同时引入新的误判。

## 当前固定参数与限制

- 摄像头：`lab_camera_view_2`
- 仪器：`instrument_006`（高速离心机）
- 时间窗口：2 秒
- 步长：1 秒
- 每个窗口：8 帧
- MiniCPM 视觉压缩：`4x`
- 真值最低置信度：0.75
- 当前仍属于三段样本上的原型验证，并不等于已经覆盖所有人员、光照、遮挡和操作方式。

新增摄像头或仪器时，需要先为该固定视角补充仪器多边形标定，再进行对应正负样本验收。
